# ES32C14 Board Images

This directory should contain the following images from the ElecTechSup ES32C14 board documentation:

1. **es32c14-pinout.jpg** - Board pinout diagram showing pin mapping and onboard resources
2. **es32c14-interfaces.jpg** - Interface descriptions (Power, RS485, Analog I/O, Digital I/O, Relays)
3. **es32c14-wiring.jpg** - Wiring diagram showing connection examples
4. **es32c14-dip-switch.jpg** - DIP switch configuration for multiplexed ports (Vo1/Io1, Vo2/Io2)

## Note
These images should be added from the actual ES32C14 board documentation provided by the manufacturer.
The documentation files reference these images, so they should be placed in this directory.
